# Trip Planner v0.3

スマホで使うことを前提にした、旅行全般向けのWeb版Trip Plannerです。

## v0.3 changes
- Disney専用の名称・PARK選択を外し、旅行全般で使えるUIへ変更
- DESTINATION入力を追加
- Memoを「入力 → ADD MEMO → 一覧保存 → DELETE」方式へ変更
- v0.2 / v0.1のlocalStorageデータを可能な範囲で自動移行
- スマホ操作向けにボタンサイズ・余白を微調整

## How to use
`index.html` をブラウザで開くだけで動作します。
GitHub Pagesにもそのまま配置できます。

データはブラウザのlocalStorageに保存されます。
