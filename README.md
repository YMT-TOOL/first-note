# First Note v0.5

## 今回の大型更新
- 左上の三本線（☰）から「MY TRIPS / 旅一覧」をスライド表示
- 複数の旅行を作成・切り替え可能
- 「＋ 新しい旅をつくる」で空の旅行ノートを追加
- 旅行ごとに以下を個別保存
  - メイン写真
  - 旅行名
  - 出発日 / 帰宅日
  - 行き先
  - コンセプト
  - スケジュール
  - チェックリスト
  - メモ
  - アルバム / 旅の記録
- 既存 v0.4.x の保存データは最初の旅行として自動移行
- 右上のリセットは「現在開いている旅行」だけを初期化

## 保存
現段階ではブラウザの localStorage に自動保存します。
同じブラウザならページを閉じても残りますが、PCとスマホの同期はまだ行いません。
将来的にアカウント + クラウド保存へ移行予定です。
