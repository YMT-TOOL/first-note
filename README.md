# First Note v0.6.7

## v0.6.7 旅の直接切り替え修正

- ID検索ではなく、一覧で押したノート本体へ直接切り替える方式に変更
- 端末容量などでローカル保存に失敗しても、ノート切り替えを止めないよう修正
- 内部IDが重複している既存データでも、選択中ノートをオブジェクト単位で管理

## v0.6.6 旅の固有情報保持・切り替え修正

- 入力を保存したときにクラウド固有番号が消える不具合を修正
- 旅一覧ではクラウド固有番号を優先して、選んだノートを直接開くよう修正
- 既に重複している古いノートがあっても切り替え可能

## v0.6.5 旅一覧の切り替え修正

- 復元・再同期で内部IDが重複したノートも、それぞれ正しく開けるように修正
- ノートをクリックしたとき、選んだ旅行の内容へ確実に切り替わるよう改善

## v0.6.4 データ保護修正
- 「端末→クラウド保存」と「クラウド→端末反映」を別ボタンへ分離
- クラウド取得による端末データの自動上書きを廃止
- クラウドから反映する直前に端末データを自動バックアップ
- 「同期前の端末データを復元」ボタンを追加
- アプリ復帰時の自動取得を一旦停止し、意図しない上書きを防止

## v0.6.3 修正
- ログイン本人専用の保存関数を使い、RLSを保ったまま確実に旅行を保存
- 「今すぐ同期」で端末内の全旅行を送信してからクラウドを再取得
- 手動同期に失敗した場合も詳しいエラーを表示
- `SUPABASE_v0.6.3追加.sql`をSQL Editorで1回実行する必要があります

## v0.6.2 修正
- 写真付きの既存旅行を初回同期すると権限エラーになる問題を修正
- 旅行本体を作成してから圧縮写真を保存する安全な順番へ変更
- 同期開始エラー時に原因メッセージを表示

## v0.6.1 修正
- クリックできるボタン・旅カード・写真欄をPCで指マーク表示
- 「端末保存」を「ログイン」へ変更
- 固定表示だった「同期中です」を「クラウド同期」へ修正
- 「今すぐ同期」を押すと「同期中…」「同期完了 ✓」をボタン上に表示
- 別タブや別アプリからFirst Noteへ戻ったとき、クラウドの最新情報を自動取得

## 今回の大型更新
- 左上の三本線（☰）から「MY TRIPS / 旅一覧」をスライド表示
- 複数の旅行を作成・切り替え可能
- 「＋ 新しい旅をつくる」で空の旅行ノートを追加
- 旅行ごとに以下を個別保存
  - メイン写真
  - 旅行名
  - 出発日 / 帰宅日
  - 行き先
  - コンセプト
  - スケジュール
  - チェックリスト
  - メモ
  - アルバム / 旅の記録
- 既存 v0.4.x の保存データは最初の旅行として自動移行
- 右上のリセットは「現在開いている旅行」だけを初期化

## v0.6 オンライン同期
- Supabase Authによるメールアドレス＋パスワード登録・ログイン
- PCとスマホで旅行データを自動同期
- 入力中は端末にも保存し、ログイン中は約0.8秒後にクラウド保存
- 初回同期時に既存の端末データをクラウドへ移行
- 別端末に既存データがある場合は、追加またはクラウド優先を選択可能
- 写真は選択時に長辺を縮小・JPEG圧縮してから非公開Storageへ保存
- 写真URLは1時間有効の署名付きURLを画面表示時に発行

## 保存先
- 端末バックアップ: localStorage
- 旅行データ: Supabase Database（trips）
- 写真: Supabase Storage（trip-photos / private）
